## ✦ About MINIMA

**MINIMA** is a premium stationery store concept created around a simple
idea: everyday paper and desk products can be functional, beautiful, and
thoughtfully designed.

The brand combines a minimalist visual identity with a curated
collection of stationery essentials for studying, planning, journaling,
writing, organizing, and creating.

MINIMA is designed to feel like a contemporary stationery boutique
rather than a generic online catalog. The experience emphasizes clean
layouts, generous spacing, product photography, refined typography, and
an understated premium aesthetic.

### Brand philosophy

> **Less clutter. More intention.**

MINIMA focuses on products that bring order and character to everyday
routines without unnecessary visual noise.

## ♿ Accessibility

Accessibility is part of the MINIMA design process.

The storefront should follow practical accessibility principles such as:

-   Semantic HTML
-   Descriptive image `alt` text
-   Keyboard-friendly navigation
-   Visible focus states
-   Sufficient text contrast
-   Clear form labels
-   Logical heading hierarchy
-   Responsive text sizing
-   Avoiding information conveyed only by color

The goal is to make the experience comfortable and understandable for as
many visitors as possible.

## 🚀 GitHub Pages

MINIMA can be deployed as a static website through GitHub Pages.

### Basic deployment

1.  Create the GitHub repository.
2.  Upload the project files.
3.  Commit the changes.
4.  Open **Settings → Pages**.
5.  Select the desired branch.
6.  Select the project root as the publishing directory.
7.  Save the configuration.
8.  Wait for GitHub Pages to publish the site.

Once published, the repository can serve as the foundation for the
MINIMA storefront.
